# Shoes Listing and Filtering Website

This project is a responsive Shoes Listing Website developed using HTML, Bootstrap 5, and JavaScript. It displays a collection of shoes in responsive product cards and allows users to find their desired shoes easily.

### Features
- **Responsive Design:** Displays shoe cards in a responsive grid across desktop, tablet, and mobile devices.
- **Brand Filter:** Filter shoes by brands such as Nike, Adidas, and Vans.
- **Color Filter:** Find shoes based on available colors.
- **Size Filter:** Display shoes according to available shoe sizes.
- **Price Range Slider:** Filter shoes by maximum price using a slider inside a dropdown menu.
- **Search Functionality:** Search shoes by brand, name, price, size, or color.
- **Dynamic Product Display:** JavaScript updates the displayed shoes according to the selected filters and search input.
- **Bootstrap Components:** Uses Bootstrap navigation, dropdowns, buttons, form controls, and responsive grid classes.

### Technologies Used
- HTML5
- Bootstrap 5
- JavaScript

### Project Objective
The main objective of this project is to practice responsive web design, Bootstrap components, JavaScript arrays, objects, filtering methods, event handling, and DOM manipulation while creating a simple and user-friendly shoe shopping interface.
